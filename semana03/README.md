# Semana 03: POO I

## Gestor de Tareas

Programa de consola con menu para agregar, listar, completar y eliminar tareas.

## Que se aprendio

Clases, objetos, constructores, encapsulacion con this, ArrayList generico
y organizacion en paquetes.

## Compilar y ejecutar

    javac -d out src/modelo/Tarea.java src/app/GestorTareas.java
    java -cp out app.GestorTareas
