# Semana 02: Fundamentos de Java

## Sistema de Calificaciones

Programa de consola que gestiona las notas de 5 estudiantes (3 notas c/u):
promedio, maximo, minimo y estado (Aprobado si promedio >= 51).

## Compilar y ejecutar

    javac -d out src/SistemaCalificaciones.java
    java -cp out SistemaCalificaciones
